# Support

Community support is provided through the issue tracker for the latest released version. Include the kit version, Python version, operating system, selected GitHub backend, the command or skill used, and redacted error output.

Do not post access tokens, credentials, private issue bodies, or confidential Project data.

The release-candidate GitHub routes are authenticated GitHub CLI and direct
GraphQL/REST. A Codex GitHub integration/GitHub MCP is usable only when its
capability preflight proves the complete Projects, fields, views, iterations,
hierarchy, dependency, and issue-type surface required by the operation. An
incomplete generic MCP is expected to fail closed; see the
[release-candidate limitations](README.md#release-candidate-support-and-limitations)
before reporting that behavior as a defect.

Commercial support and service levels are available only through a separate agreement. See [COMMERCIAL.md](COMMERCIAL.md).
